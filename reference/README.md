# reference/ — the finished app (answer key)

This directory is **not** part of the exercise. It holds one completed, correct build of
Click Farm — all four sprints done — so you can:

- **Just play it.** Open `reference/index.html` in a browser. No setup, no loop run, no tokens.
- **Diff against it** if your own loop run goes sideways and you want to see one version that passes.

It is *an* answer, not *the* answer. A real loop run will produce its own `index.html` at the
repo root that may look different and still be completely correct — there are many ways to satisfy
the specs. The exercise is the root of the repo; this is just the back of the book.
